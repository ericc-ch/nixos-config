# Wait what (bro)

You lost the user or spoke in machine jargon. Back up and say that again like one human talking to another.

## Rules

- **Decide how far back to go:** What lost the user is often bigger than the last message. Find the root assumption.
- **Add the premise the user missed:** Do not merely delete words. Explain the missing step or context that connects the ideas.
- **Drop the jargon:** Speak plainly and directly. Stop sounding like an academic paper or a chatbot. Talk like a knowledgeable teammate at a whiteboard.
- **Keep sentences short and concrete:** Use project terms, active verbs, and everyday words. Follow `unslop` rules.
- **End with one check:** Ask one targeted question to confirm what is still unclear.

You are done when the second try is shorter and clearer, not shorter and blunter.
