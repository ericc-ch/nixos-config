You lost the user. Back up and say that again in plain words.

- Decide how far back to go. What lost the user is often bigger than one message.
- Add the premise the user missed. Do not only cut words.
- Use short sentences and project terms. Follow `simple-english` rules for style.
- End with one check. Ask what is still unclear.

You are done when the second try is shorter and clearer, not shorter and blunter.
