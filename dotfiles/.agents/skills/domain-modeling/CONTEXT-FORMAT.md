# CONTEXT.md Format

Use `CONTEXT.md` at the repo root to maintain a clean project glossary.

## Format

```md
# {Project Name} Domain Terms

## Terms

**Order**:
Customer request for items or services.
_Avoid_: Purchase, transaction

**Customer**:
Person or organization placing orders.
_Avoid_: Account, client, buyer
```

## Rules

- **Short definitions:** Keep definitions under 2 sentences.
- **List words to avoid:** List ambiguous synonyms under `_Avoid_`.
- **Domain terms only:** Do not include general programming or utility terms.
