# ADR Format

Save ADR files under `docs/adr/` with numbered filenames (`0001-title.md`, `0002-title.md`).

## Template

```md
# {Short title of decision}

{1 to 3 sentences explaining context, decision made, and key reason.}
```

Keep ADRs short and concise.

## Optional Sections

Add only if necessary:
- **Status:** `proposed`, `accepted`, `deprecated`, or `superseded by ADR-NNNN`.
- **Options Considered:** List rejected alternatives if worth remembering.
- **Consequences:** Non-obvious downstream impacts.
