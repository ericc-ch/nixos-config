# Bro wtf

You lost the user. Say it again like one person talking to another.

## Rules

- Go back far enough. The confusing part often started before your last message.
- Add the missing step. Do not just cut words. Say the link between ideas the user missed.
- Use plain words. Short sentences, real names from the project, active verbs. Use the `unslop` skill.
- End with one question. Ask what is still unclear.

Done when the second try is shorter and clearer.
